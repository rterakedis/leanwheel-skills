# StoreApp — brief

StoreApp helps solo landscapers plan the day's jobs. Core features shipped in 1.0:
a job list sorted by drive time, one-tap "on my way" texts to clients, and a daily
earnings summary. Pro (monthly subscription) removes the 10-job limit.
Audience: owner-operators with one truck. Support: https://example.com/support
Privacy: https://example.com/privacy
