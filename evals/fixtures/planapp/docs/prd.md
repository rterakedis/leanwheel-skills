# PlanApp — PRD

A small iOS invoicing app for freelancers (SwiftUI, iOS 18+).

## Functional requirements
- **FR-1** A freelancer can create a draft invoice with one or more line items.
- **FR-2** A freelancer can send a draft invoice to the client. Sending is one-way: a sent invoice is never editable or re-sendable.
- **FR-3** The invoice list shows each invoice's status (Draft, Sent).

## User journeys
- **UJ-1** Freelancer finishes a draft, taps Send, sees the invoice marked Sent.
